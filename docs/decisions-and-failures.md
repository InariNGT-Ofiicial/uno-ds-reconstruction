# 失败尝试与最终取舍

这些记录的价值在于说明约束为什么需要存在。它们不是把所有历史试验都说成最终采用的方法。

| 尝试／错误 | 观察到的问题 | 最终处理 |
|---|---|---|
| 固定4 fps作为生产目标 | 网格会漏掉新手势，也会为重复姿态多画图 | 改为保留真实动作切换与极点；均匀联系表只导航 |
| 沿初音发型蒙版描改 | 双马尾边界限制DS散发，旧白边也可能留住 | 放弃该人物蒙版路线，采用原生整帧编辑与审计 |
| 完整F005做身份供体 | 模型把母稿的脸、手、牌位置也带过来 | 换成保留整片后发连接的hair-only参考板 |
| 只截发梢碎片 | 没有整头与后发的连接信息 | 辅助板保留完整大束关系，局部只补头饰细节 |
| 把所有相似嘲讽稿归成两张 | 同侧镜头其实交换了持牌手和张手 | 1560与1620新画整姿态，副歌复奏复用同一文件 |
| 单稿覆盖整个V指镜头 | 漏倾头反转、瞟眼和嘴形变化 | 两个重点段分别补4与5份原生稿，按实际切点安排曝光 |
| 把plead_B当连接抖动 | 实际有V手／牌向外摆的清楚极点 | 恢复A/B动作，修B中央刘海尖端，再把叹气字独立出来 |
| 只检查发型不检查五指 | 开场旧A母稿本来少拇指，后续稿继承 | 新发现作为解剖硬错单独修；不把母稿标签当全身正确证明 |
| 相邻抬手稿独立重造头发 | 新生外钩、头饰冠高变化 | B沿A冻结结构定向修，保留B当前手势和表情 |
| 相同姿态再生一张“更统一” | 仍会增加新卷钩／纹理，造成新的差异 | 重复段精确引用通过文件与哈希 |
| 源文字直接贴屏幕坐标 | 原片框在移动，停格稿框不动，文字出框 | 文字适配当前采用稿气泡的内部槽位 |
| 图层提取只看无绿色 | 气泡仍夹带渐变转场条；低位框还被裁掉 | 重建独立平涂气泡、内部白字和明确的完整图形hold |
| 以一次渲染成功当全部验收 | 后续实际观看仍发现漏动作和图文错位 | 区分覆盖、静态审稿、相邻关系、实际编码检查 |

## 开场的两次决定不矛盾

第一轮为了减少头饰跳变，把开场统一为B稿。全片源动作审计后来指出，原片确有A/B招手曝光，于是补画A并修牌位、头饰和拇指。最后用户明确要求“开头两帧用一帧就好”，当前版本因此再次统一成B。

这不是自动评测把A/B判成了相同姿态，而是最终人工取舍。当前规则写在 `revision-v3-plan.json`，优先于历史审计中的恢复建议。

## 历史审计与当前状态

`evidence/action-key-review.json`、`evidence/hair-adjacency-review.json`保存的是对应修订阶段的证据。最终时间线以 `project/edit-plan.json`及两个显式revision文件为准，最终成片验收以 `evidence/final-film-review.json`为准。

不要从旧文档里的“单张通过”推出后来的所有合成也通过；也不要从最新成片通过推出每个历史候选都可用。提示词记录保留退稿和修稿，调用数因此大于采用图数。
